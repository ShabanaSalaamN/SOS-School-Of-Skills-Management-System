# 🎓 SOS School of Skills Management System

A Python-based **School Management System** developed using **Object-Oriented Programming (OOP)** concepts.

## 📌 Features

* 👨‍🎓 Student Management
* 👩‍🏫 Staff Management
* 📚 Program Management
* 📅 Student & Staff Attendance
* 💰 Fee Collection & Payment Tracking
* 📢 Notice Management
* 🗑️ Soft Delete & Restore
* 🔍 Search Students, Staff & Programs

## 🧠 OOP Concepts Used

* Classes & Objects
* Inheritance
* Encapsulation
* Abstraction
* Class & Instance Methods
* Class & Instance Variables
* `super()`
* Private Variables

## 🛠️ Technologies

* Python
* Object-Oriented Programming
* Streamlit
* Git & GitHub
